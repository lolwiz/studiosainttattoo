Como criar o repositório e o token?
  1. No GitHub, crie um repositório privado chamado saint-dados (marque "Add a README").
  2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Em Repository access, escolha Only select repositories e marque saint-dados.
  4. Em Permissions, clique em Add permissions, procure Contents e escolha Read and write.
  5. Gere e copie o token. Ele começa com github_pat_.
